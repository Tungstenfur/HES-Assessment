# Website Development

Create a simple HES Systems Department website using HTML and CSS.
The website should be designed as an internal website for the Systems Department.

## **Requirements**

Your website must include:

- A navigation/header
- A homepage or dashboard
- At least **3 different sections**
- A section displaying example system statuses
- At least **one button or interactive-looking element**
- **Responsive design**
- Clean and organized HTML/CSS

**All information may be hardcoded.**
**You do not need to use APIs, databases, backends, authentication, or external services.**

## Creativity:

There is no required visual design.

You may choose your own:

- Colors
- Layout
- Fonts
- Animations
- Icons
- Dark/light theme
- Dashboard style
- Other visual elements

We want to see your own design and creativity.

The website should work by simply opening **index.html** in a browser.
